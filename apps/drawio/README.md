# draw.io

Diagramming and whiteboarding for FynnCloud.

## Features

- Create flowcharts, network diagrams, UML, wireframes, and ERDs.
- Open and edit `.drawio`, `.drawio.xml`, `.drawio.svg`, `.drawio.png`, and `.diagram` files directly from the file browser.
- Automatic saving back to FynnCloud storage.
- Light and dark theme synchronization with FynnCloud.
